# Spotify-display
A display to display the time + the current playing song in my spotify playlist i think this is relatively easier than the projects that i have, however i think it is really awesome to have a mini display that can show time and the currently playing spotify display. 

Id love if i was able to use an oled display instead of the LCD, because it would look a lot better with a better quality. Though the budget does not allow it, so i have to stick with this LCD.
